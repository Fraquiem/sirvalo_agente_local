# Frontend - Agente de Cócteles

Interfaz de usuario construida con React, Vite y Supabase.

## Requisitos

- Node.js 18+

## Instalación

1. Instalar dependencias:
   ```bash
   npm install
   ```

## Ejecución

```bash
npm run dev
```

## Estructura

- `src/main.jsx`: Punto de entrada de React.
- `src/App.jsx`: Componente principal.
- `src/components/`: Componentes reutilizables (pendientes).
- `src/hooks/`: Hooks personalizados para Supabase y API (pendientes).
